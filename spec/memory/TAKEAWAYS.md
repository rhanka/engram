  - All Git/PR serialization (`D34=engram`, `D29=both`): `engram` specs, `Track` per-PR event journal + state snapshot linked by fingerprint, and per-workspace/repository `h2a` harness overlays (`D31`) `[FACT: memory-dossier/owner-r15/answers-2026-11-08.compact.md:5; memory-dossier/owner-r15/comments-2026-11-08.md:14]`.

- **What it owns:**
  - The master harness (`D31`), which the engram dreaming agent reviews in a multi-repo audit.   - `Track` as the project decision and project event analyst/controller reading `engram` via `cluster-mesh` (`R12`, `D24`, `D32`) and replaying `engram`'s per-PR serialization before merge (`D34`) `[FACT: memory-dossier/owner-r15/comments-2026-11-08.md:9,15-16; memory-dossier/owner-r15/answers-2026-11-08.compact.md:5]`.
